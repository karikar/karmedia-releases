## Frissítés

A telepített KarMedia magától jelzi, ha új verzió jelent meg (*Menü → Frissítések keresése*),
és egy gombnyomással letölti és telepíti. Az új verzió a régi helyére települ, a beállítások,
kedvencek és források megmaradnak.
